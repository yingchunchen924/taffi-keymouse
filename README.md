# 塔菲键鼠 3.0

塔菲键鼠 3.0 是一个面向普通用户的 Windows 本地键鼠自动化工具。它支持录制鼠标、键盘操作，把操作保存为脚本，并按脚本顺序回放；也支持基础的图片识别步骤，用于在回放过程中确认界面或点击目标。

## 主要功能

- 脚本库管理：新建、复制、改名、删除、导入、导出脚本。
- 键鼠录制：记录鼠标移动、点击、滚轮和键盘操作。
- 脚本回放：支持单次、指定次数、一直循环三种模式。
- 步骤编辑：可以添加等待、文本输入、识图点击、识图校验。
- 图片识别：导入参考图，试找一次，回放时按步骤查找。
- 安全控制：急停热键、屏幕角落急停、回放前检测脚本风险。
- 运行记录：保存最近运行状态，便于排查失败原因。

## 安装依赖

建议使用 Python 3.10 或更高版本。

```powershell
pip install -r requirements.txt
```

## 启动

```powershell
python main.py
```

程序数据默认保存在 Windows 用户目录：

```text
%APPDATA%\塔菲键鼠3.0
```

其中包含数据库、脚本快照、参考图、日志和导出文件。仓库不会上传这些本地数据。

## 打包

安装 PyInstaller 后，可以运行：

```powershell
.\build.ps1
```

打包完成后会在项目目录生成 `塔菲键鼠3.0.exe`。

## 安全提醒

塔菲键鼠用于本地桌面自动化。请不要用它录制或回放密码、验证码、支付信息等敏感内容，也不要用于绕过游戏、软件或网站的安全规则。回放前建议先小范围测试，并熟悉急停方式。

默认急停方式：

- `Ctrl + Shift + F12`
- 将鼠标移到屏幕角落
