# 塔菲键鼠 3.2.2

塔菲键鼠是一个面向普通用户的 Windows 本地键鼠自动化工具。它可以录制鼠标、键盘动作，把操作保存成脚本，并按脚本顺序回放；也支持基础图片识别步骤，用来在回放过程中确认界面、寻找按钮或点击目标。

它的定位不是复杂编程平台，而是一个打开就能用的本地自动化工作台：新建脚本，开始录制，停止保存，再回放验证。

## 适合做什么

- 重复点击、重复输入、重复执行桌面流程。
- 把常用窗口操作录成脚本，后续一键回放。
- 用文件夹管理不同用途的脚本，例如工作、游戏、测试、临时任务。
- 给脚本加入等待、文本输入、识图点击、识图校验等步骤。
- 通过运行记录排查脚本为什么停止、失败或跑偏。

## 主要功能

### 脚本库

- 新建、复制、改名、删除脚本。
- 文件夹分类管理脚本。
- 脚本可移动到指定文件夹。
- 删除文件夹时，里面的脚本会安全移回“未分类”。
- 支持搜索脚本。
- 支持导入、导出脚本。
- 文件夹展开/折叠状态会保存，重启后保持上次状态。

### 键鼠录制

- 录制鼠标移动、点击、松开、滚轮。
- 录制键盘按下和松开。
- 支持将粘贴文本识别为“输入文本”步骤。
- 自动忽略塔菲键鼠窗口内的录制点击，减少误录。
- 可调节录制移动精度，控制鼠标移动步骤的细腻程度。

### 脚本回放

- 单次回放：适合测试脚本。
- 指定次数：适合固定次数重复任务。
- 一直循环：适合持续执行任务，需要手动停止。
- 支持开始前倒计时。
- 支持回放速度设置。
- 支持每轮循环间隔。
- 回放过程中可以暂停、继续、停止。
- 停止或急停时会释放已按下的键和鼠标按钮，降低卡键风险。

### 步骤编辑

- 步骤列表可查看每一步动作和时间。
- 可手动添加文本输入。
- 可手动添加等待。
- 可添加识图点击。
- 可添加识图校验。
- 可编辑、删除、上移、下移步骤。

### 图片识别

- 导入按钮、图标、固定界面元素截图作为参考图。
- 支持“试找一次”，确认当前屏幕是否能找到图片。
- 识图点击：回放到该步骤时查找图片，找到后点击图片中心。
- 识图校验：回放到该步骤时检查图片是否出现，找不到可停止脚本。
- 可设置识图灵敏度。
- 可设置坐标修正半径，让普通点击在附近参考图辅助下更稳。

### 安全与排查

- 支持 `Ctrl + Shift + F12` 急停。
- 支持鼠标移动到屏幕角落急停。
- 回放前可以检测脚本风险。
- 运行记录会保存开始时间、结束时间、状态、循环次数和失败信息。
- 首次启动会显示安全说明，提醒不要录制密码、验证码、支付信息。

### 界面体验

- 支持窗口置顶。
- 支持从顶部区域自由拖动窗口，方便露出屏幕边缘区域。
- 支持日间模式和夜间模式。
- 夜间模式会保存为本地设置，关闭重开后继续保持。

## 安装依赖

建议使用 Python 3.10 或更高版本。

```powershell
pip install -r requirements.txt
```

## 启动

```powershell
python main.py
```

## 数据目录

程序数据默认保存在 Windows 用户目录：

```text
%APPDATA%\塔菲键鼠数据
```

其中包含数据库、脚本快照、参考图、日志、导出文件和本地设置。3.2.1 起使用版本无关的数据目录，后续升级不会因为版本号变化而更换脚本库。

首次启动新版时，会自动从旧的 `%APPDATA%\\塔菲键鼠3.0` 目录复制数据到新目录，并保留旧目录作为备份。仓库不会上传这些本地数据。

## 打包

安装 PyInstaller 后，可以运行：

```powershell
.\build.ps1
```

打包完成后会在项目目录生成 `塔菲键鼠3.2.2.exe`。

## 注意事项

- 如果目标程序以管理员身份运行，塔菲键鼠也需要以管理员身份运行，否则可能录不到键盘或回放无效。
- 某些游戏、反外挂、受保护窗口可能拦截键盘监听或模拟输入。
- 请先用记事本等普通窗口测试键盘录制，再用于复杂目标窗口。
- 不建议录制密码、验证码、支付信息。
- 不建议用于绕过软件、网站或游戏的安全规则。
